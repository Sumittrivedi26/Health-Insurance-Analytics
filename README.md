## 🏥 Health Insurance Dataset Analysis

This project involves a comprehensive analysis of a health insurance dataset using Python. The goal is to understand the relationship between various demographic and health-related factors (such as age, BMI, smoking habits, and region) and the insurance charges.

📂 Dataset
The dataset used is insurance.csv, which includes:
age: Age of primary beneficiary
sex: Gender of the beneficiary
bmi: Body Mass Index
children: Number of children covered by health insurance
smoker: Smoking status
region: Residential area in the US
charges: Medical costs billed by health insurance

## 🔍 Project Highlights

📥 Data Loading & Cleaning
Removed duplicate rows
Checked for nulls and unique values

## 📊 Exploratory Data Analysis

Analyzed distribution of charges
Studied how smoking affects insurance charges
Visualized correlations between numerical variables
Compared charges by region, gender, and number of children

## 📈 Insights

Smoking significantly increases medical charges
BMI and age are moderately correlated with charges
Gender does not have a significant effect on charges
Regional variations in charges are minor
